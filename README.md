# javascript-lotto-precourse

### ‼️ 예외 처리 고려 사항

### 0. 공통

- 값이 비어있지 않은지 검증
  - [ ] 값이 비어있다면 ERROR
- 값이 올바른 양의 정수 숫자 형식인지 검증
  - [ ] 값이 양의 정수가 아니라면 ERROR
- 값이 올바른 로또 번호 형식인지 검증
  - [ ] 값이 1부터 45 사이가 아니라면 ERROR
  - [ ] 기존 로또 번호와 중복이라면 ERROR

### 1. 로또 구입 금액 (money)

- [ ] [공통] 값이 비어있지 않은지 검증
- [ ] [공통] 값이 올바른 양의 정수 숫자 형식인지 검증
- [ ] 값이 1000으로 나눠떨어지지 않는다면 ERROR
- [ ] 값이 너무 크다면 ERROR

### 2. 당첨 번호 문자열 (winningNumberString)

- [ ] [공통] 값이 비어있지 않은지 검증

- [ ] 문자열에 구분자가 없다면 ERROR
- [ ] 문자열이 구분자로 시작하거나 구분자로 끝나면 ERROR

### 3. 당첨 번호 배열 (winningNumbers)

- 배열의 각 값에 대해서
- [ ] [공통] 값이 비어있지 않은지 검증
- [ ] [공통] 값이 올바른 양의 정수 숫자 형식인지 검증
- [ ] [공통] 값이 올바른 로또 번호 형식인지 검증
- [ ] 배열의 길이가 6이 아니라면 ERROR

### 4. 보너스 번호 (bonusNumber)

- [ ] [공통] 값이 비어있지 않은지 검증
- [ ] [공통] 값이 올바른 양의 정수 숫자 형식인지 검증
- [ ] [공통] 값이 올바른 로또 번호 형식인지 검증
